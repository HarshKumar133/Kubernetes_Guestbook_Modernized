🚀 Quick Start

To run the complete application, you'll need to install the required tools and follow these steps:

Prerequisites:

  • Google Cloud SDK (gcloud)
  • Terraform >= 1.0
  • Helm >= 3.0
  • kubectl
  • Docker (for local development)

Installation Steps:

  1. Install required tools using the setup script
  2. Configure Google Cloud credentials
  3. Deploy infrastructure with Terraform
  4. Deploy application with Helm
